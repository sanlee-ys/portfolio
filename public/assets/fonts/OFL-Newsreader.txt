Files in this directory, and where each came from:

  newsreader-latin.woff2, newsreader-latin-italic.woff2
  newsreader-latin-ext.woff2, newsreader-latin-ext-italic.woff2
      Newsreader, variable weight axis 200-800, roman and true italic. Cut by
      ../../../scripts/subset-fonts.py from the upstream variable fonts in
      google/fonts (ofl/newsreader): Newsreader[opsz,wght].ttf and
      Newsreader-Italic[opsz,wght].ttf, version 1.003.

      Upstream carries an optical-size axis (opsz 6-72) alongside weight. The
      script pins opsz at its own default (18) and keeps the weight axis only,
      which reproduces the "wght instance" files these four were previously
      copied from ("@fontsource-variable/newsreader" v5.3.0). The two-axis
      files are roughly 2.3x the bytes for a grade most readers never
      consciously see; the reasoning is in the Newsreader block at the top of
      ../style.css.

      Only the latin and latin-ext subsets are kept, at Google Fonts' own
      unicode ranges. No arrows are added here, unlike the Geist files:
      Newsreader has no arrow glyphs upstream at any weight, so prose arrows
      come from geist-arrows.woff2 instead. Neither npm package is a
      dependency of this site; only the generated woff2 files are committed.

  newsreader-won.woff2
      The won sign (U+20A9) alone, cut from the same Newsreader source by the
      same script. It exists because Geist has no won sign at any weight, and
      public/resume.html -- which is deliberately standalone and sets an
      all-Geist stack -- uses one. Without it that character came from the
      platform, which made the committed resume.pdf embed a different face for
      it depending on which machine last generated the file.
